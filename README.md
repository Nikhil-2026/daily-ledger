# Daily Ledger

Daily Ledger is a web application used to manage daily expenses, income, and business transactions.

## Features
- User login and signup
- Add multiple ledgers
- Track daily expenses and income
- Manage pending payments
- View monthly summaries
- Maintain activity history
- Voice input for entering details
- Export records to CSV

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Web Speech API

## How to Run
1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Sign up or log in to use the application.

## Objective
To make daily expense and income tracking simple and organized.
